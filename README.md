# Store Management

A custom Odoo 19 module for managing store
operations, products, customers, and sales orders.

## Features
- Product management customizations
- Customer management customizations
- Sales order customizations
- Custom views and menus
- Sequence configuration

## Requirements
- Odoo 19.0
- PostgreSQL
- Python compatible with Odoo 19

## Installation
1. Copy the module into your custom addons directory.
2. Configure the `addons_path`.
3. Restart the Odoo server.
4. Update the Apps list.
5. Install the Store Management module.

## Project Structure
- `models/` - Python business logic
- `views/` - XML user interface definitions
- `data/` - Module data and sequences
- `__manifest__.py` - Module configuration
